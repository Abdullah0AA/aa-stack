# aa-stack

An opinionated full-stack starter with end-to-end type safety through Hono RPC.

- **Monorepo:** Vite+, pnpm workspaces and catalogs
- **Web:** React, TanStack Router and Query, shadcn
- **Backend:** Hono, Bun, Drizzle

## Getting started

Requires [Vite+](https://viteplus.dev).

```bash
vp create aa-stack -- my-app
cd my-app
vp install
vp run dev:full
```

This starts the web app and an example books API.
